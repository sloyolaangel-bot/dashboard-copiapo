DASHBOARDS COPIAPÓ — AUTOACTUALIZACIÓN PÚBLICA

OBJETIVO
Los dashboards ya no dependen de cargar el Excel manualmente en tu navegador para que otras personas vean la actualización.
Al abrir cada panel desde GitHub Pages, el HTML intenta leer automáticamente un archivo llamado:
    reporte.xlsx
ubicado en la MISMA carpeta del dashboard.

ESTRUCTURA EN GITHUB
dashboard-copiapo/
  gestion-comercial/
      index.html
      reporte.xlsx
  cruce-captacion/
      index.html
      reporte.xlsx
  av-sav-cesantia/
      index.html
      reporte.xlsx
  vida-salud/
      index.html
      reporte.xlsx
  renegociacion/
      index.html
      reporte.xlsx

QUÉ EXCEL SUBIR
- gestion-comercial/reporte.xlsx:
  Pulso Diario de Negocio actualizado.

- cruce-captacion/reporte.xlsx:
  ZC Panel Seguros CCSS actualizado.

- av-sav-cesantia/reporte.xlsx:
  El mismo ZC Panel Seguros CCSS actualizado.

- vida-salud/reporte.xlsx:
  El mismo ZC Panel Seguros CCSS actualizado.

- renegociacion/reporte.xlsx:
  Archivo actualizado de Efectividad / Renegociaciones.

RUTINA DIARIA
1. Descarga los Excel del día.
2. Renombra cada fuente como reporte.xlsx.
3. En GitHub reemplaza solamente el reporte.xlsx de la carpeta correspondiente.
4. Espera el ✓ verde de github-pages.
5. No cambies el link de WhatsApp. El mismo link mostrará la información nueva.

IMPORTANTE
- Los botones de carga manual siguen funcionando como respaldo.
- El botón “← Volver al Portal” sigue incluido.
- Se usa cache:'no-store' y un parámetro de tiempo para evitar que el navegador conserve un Excel antiguo.
- Si reporte.xlsx falta o tiene una estructura incorrecta, el dashboard conserva sus datos incluidos como respaldo y muestra un aviso.
